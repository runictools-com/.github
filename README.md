# RunicTools organization defaults

This repository owns the public GitHub organization profile and the default collaboration files inherited by RunicTools repositories that do not define their own.

- `profile/README.md` — public organization profile
- `COLLABORATION.md` — practical workflow for maintainers
- `CONTRIBUTING.md` — contribution contract
- `SECURITY.md` — private vulnerability reporting
- `.github/ISSUE_TEMPLATE/` and `PULL_REQUEST_TEMPLATE.md` — shared work templates

Product source remains in each product repository. Never place credentials, production data, backups, or `.env` files here.
