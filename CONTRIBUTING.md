# Contributing to RunicTools

Thank you for improving a RunicTools project.

1. Check the repository README and `AGENTS.md` for project-specific commands and safety rules.
2. Work from the current default branch on a focused branch.
3. Keep credentials, personal data, production exports, and generated backups out of commits.
4. Run the repository's tests, lint, and build commands before opening a pull request.
5. Describe the outcome, risk, validation evidence, and any deployment or migration step in the pull request.

Project-specific instructions take precedence over these organization defaults.
